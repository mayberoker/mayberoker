### Nclient-R

<a href="https://github.com/mayberoker/Nclient-R"><img src="https://raw.githubusercontent.com/mayberoker/Nclient-R/main/docs/assets/showcase.jpg" width="100%" alt="Nclient-R screenshots"></a>

- 🖤 **Pitch-black liquid-glass design**, red accents, rounded everything
- ⚡ **Zero-buffer full-resolution reader** with whole-gallery preloading
- 🏷️ **Every tag** nhentai has, each one Include · Neutral · Exclude
